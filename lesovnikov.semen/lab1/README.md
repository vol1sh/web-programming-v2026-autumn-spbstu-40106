# Лабораторная работа 1

## Задание

Вариант 13. Создать блок с текстом. Текст может быть любой длины. Необходимо
реализовать с помощью CSS механизм, который будет скрывать текст, если он
превышает высоту 100 пикселей или 3 строки. Если текст выходит за пределы
указанного лимита, он должен обрезаться и заменяться многоточием (…). Текст
должен иметь шрифт Arial, размер шрифта — 16px.

## Реализация

- В разметке создан текстовый блок с селектором `.text-clamp`.
- Для скрытия переполнения и отображения многоточия применены
  `overflow: hidden`, `text-overflow: ellipsis`, а также `display: -webkit-box`,
  `-webkit-box-orient: vertical`, `-webkit-line-clamp: 3` и `line-clamp: 3`.
- Для ограничения по высоте задано свойство `max-height: 100px`.
- Установлены правила типографики: шрифт Arial, размер 16px, `line-height: 1.5`.

## Запуск

Откройте `index.html` в браузере.
