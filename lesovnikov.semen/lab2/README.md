# Лабораторная работа 2

## Задание

Вариант 13. Сделайте функцию, которая параметром будет получать дату, а
возвращать знак зодиака, соответствующий этой дате.>

## Реализация

- Реализован именованный ES-экспорт функции `getZodiacSign(date)`.
- Функция использует data-driven подход: календарные границы (массив `CUTOFFS`)
  и названия знаков зодиака (массив `SIGNS`) вынесены в константы модуля.
- Вычисление выполняется за $O(1)$ без вложенных ветвлений `if` на основе
  индекса месяца (`getMonth()`) и дня (`getDate()`).
- Возвращается русскоязычное название знака зодиака с заглавной буквы.
- Исходный объект `Date` не мутирует.

## Запуск

Импортируйте функцию в проект:

```javascript
import {getZodiacSign} from './solution.js';

console.log(getZodiacSign(new Date(2026, 3, 12))); // Овен
```
