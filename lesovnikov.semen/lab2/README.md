# Лабораторная работа 2

## Задание

Вариант 13. Сделайте функцию, которая параметром будет получать дату, а возвращать знак зодиака, соответствующий этой дате.

## Реализация

- Реализован именованный ES-экспорт функции `getZodiacSign(date)`.
- Функция извлекает день (`getDate()`) и месяц (`getMonth() + 1`) из переданного объекта `Date`.
- Определение знака зодиака производится по календарным интервалам классической астрологии.
- Функция возвращает корректное русскоязычное наименование знака зодиака с заглавной буквы ('Овен', 'Телец', 'Близнецы', 'Рак', 'Лев', 'Дева', 'Весы', 'Скорпион', 'Стрелец', 'Козерог', 'Водолей', 'Рыбы').
- Исходные данные не мутируют.
