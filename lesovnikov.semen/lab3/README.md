# Лабораторная работа 3

## Задание

Вариант 13. Реализуйте функцию sortByFrequency(arr), которая сортирует элементы массива по частоте встречаемости.

## Реализация

- Реализован именованный ES-экспорт функции `sortByFrequency(arr)`.
- Подсчёт частоты появления элементов выполняется с помощью коллекции `Map`, что обеспечивает поддержку ключей произвольного типа данных.
- Сортировка выполняется по убыванию частоты встречаемости элементов.
- Исходный массив не мутирует: для сортировки создаётся поверхностная копия массива (`[...arr]`).

## Запуск

1. Подключите функцию в модуль JavaScript:
```javascript
import { sortByFrequency } from './solution.js';

console.log(sortByFrequency([1, 2, 2, 3, 3, 3])); // [3, 3, 3, 2, 2, 1]
